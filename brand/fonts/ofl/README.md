# Open-licence display faces for art directions

Free fonts under the SIL Open Font License 1.1 (licence texts alongside, `OFL-<family>.txt`), for the
period type an art direction sets in its own world. PP Neue Montreal stays the face of the house end card.
Each file is the Latin subset Google Fonts serves (fonts.gstatic.com), saved as woff2.
